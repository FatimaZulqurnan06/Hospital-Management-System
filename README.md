# Hospital-Management-System
A complete Hospital Management System developed in C++ using Object-Oriented Programming principles and SFML GUI integration.

## Features
- Patient Management
- Doctor Management
- Appointment Booking
- Billing System
- Prescription Management
- Admin Panel
- Login Authentication
- File Handling
- SFML Graphical User Interface

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- SFML
- File Handling
- Dynamic Memory Allocation
- Templates

## OOP Concepts Used
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction
- Composition
- Aggregation
- Templates

##How To Run
Requirements
Visual Studio
SFML Library
C++17 or later

##SFML Setup
Include Directories
SFML/include
Library Directories
SFML/lib
Linker Dependencies

For Release Mode:
sfml-graphics.lib
sfml-window.lib
sfml-system.lib

For Debug Mode:
sfml-graphics-d.lib
sfml-window-d.lib
sfml-system-d.lib

##How To Compile
Open the project in Visual Studio
Configure SFML paths
Build the project
Run main.cpp
